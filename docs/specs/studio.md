5November: start with paintings/posters, continue with lamps. It specifies no
software features. The portfolio goal and owner delegation authorize choosing
an application and publishing personal GitHub/Vercel. This studio is that
execution choice; it does not redefine physical sales or AI generation as done.

Provide three original deterministic poster families and three palettes, five
portrait dimensions, margins, variants, frame/wall controls and a proportional
room view. Add floor, pendant and table lamp concepts with finite size/height,
side and warmth controls. The halo is explicitly illustrative. SVG poster
exports include only the artwork at selected physical dimensions; PNG previews
have2400px long edge and make no300dpi promise. Export a room SVG and strict
versioned JSON project. Keep text literal and forbid external image/script data.

Every Save creates a new immutable local version. Web Locks serialize the
read/append/write cycle; re-read latest data inside the lock, validate before
writing and refuse intervening changes. Delete only an explicitly confirmed
unchanged record. Never overwrite malformed data or silently replace the current
draft on storage events/import/open. Give corrupt-library raw recovery and
portable export paths. No cloud synchronization, account, provider, payment,
manufacturing, broad electrical calculation or real-world product catalogue.

Use native form controls/dialogs, keyboard tab navigation, explicit errors,
reduced motion, narrow touch layout, and a strict published allowlist. Inputs
and exports carry finite budgets. No local heavy runtime after Storage Guard
refusal. A source/static pass is separate from actual browser/download/hosting
qualification; retain original failed checks and scoped cleanup evidence.

Inspected implementation references:
[Canvas toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)
documents PNG output/null failures and browser resolution metadata;
[object URL lifetime](https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static)
requires releasing temporary image/download URLs after use. SVG output stays
vector-based and distinct from raster preview resolution.
